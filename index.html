Windows App Installer

Interaktivt PowerShell-script som installerer apper via winget med menybasert UI.

Hurtigstart

Åpne PowerShell som Administrator og kjør:

irm https://olewol.github.io/windows-installer/install.ps1 | iex

Parametere

# Installer alt uten meny
.\install.ps1 -All

# Kun core-apper
.\install.ps1 -Core

# Kun dev-apper
.\install.ps1 -Dev

# Vis full liste
.\install.ps1 -List

# Hopp over spesifikke apper
.\install.ps1 -All -Skip "Git,7-Zip"

# Hjelp
.\install.ps1 -Help
